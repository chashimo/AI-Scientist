## Plot Descriptions

### Hit Rates Plot
- **Filename:** hit_rates.png
- **Description:** This plot illustrates the hit rates for each experiment. The hit rate is calculated as the number of videos correctly identified as propaganda divided by the total number of videos analyzed. It provides a visual comparison of the effectiveness of each prompt variant in detecting anti-Japan propaganda. The baseline achieved the highest hit rate, while the addition of negative/neutral examples resulted in the lowest hit rate.

### Total Hits Plot
- **Filename:** hits.png
- **Description:** This plot shows the total number of hits (videos identified as propaganda) for each experiment. It highlights the absolute number of successful detections across different prompt configurations. The baseline and the clarified scale anchors experiments had similar high numbers of hits, whereas the experiment with negative/neutral examples had significantly fewer hits.

### Total Videos Analyzed Plot
- **Filename:** total_videos.png
- **Description:** This plot displays the total number of videos analyzed in each experiment. It serves as a reference to ensure that each experiment was conducted on the same dataset size, maintaining consistency across the experiments. All experiments analyzed the same number of videos, ensuring a fair comparison of results.
